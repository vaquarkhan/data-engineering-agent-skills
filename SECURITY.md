# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, do not open a public issue with exploit details.

Instead:

1. open a private GitHub security advisory if available for the repository
2. or contact the maintainer through GitHub with:
   - affected files or component
   - impact summary
   - reproduction steps
   - suggested mitigation if known

## Scope

This repository contains:

- workflow instructions for AI agents
- templates and examples
- installer extensions and plugin scaffolds
- automation workflows and hooks

Security issues are especially important when they affect:

- installer behavior
- release packaging
- credentials or secrets handling
- generated workflow guidance that could encourage unsafe production changes

## Expectations

- give maintainers a reasonable window to investigate before public disclosure
- avoid publishing private credentials, tokens, or tenant-specific details in reports
- include the smallest reproducible example that demonstrates the issue
