# Walkthroughs

This document outlines the walkthrough assets that make the repository easier to adopt.

## Suggested GIFs Or Screenshots

1. install the skill pack into a project with `scripts/install.sh`
2. choose a starter pack from `starter-packs/`
3. start from a contract template in `templates/`
4. open one example pack and run the minimal commands
5. pick a platform preset and matching workflow skills

## Suggested Walkthrough Flow

```text
choose starter pack
  -> select platform preset
  -> load workflow skills
  -> copy templates
  -> run example scaffold
  -> adapt to project
```

## Good Demo Scenarios

- AWS lakehouse onboarding
- Databricks medallion modeling
- dbt marts with governed metrics
- Kafka and Flink streaming incident recovery
