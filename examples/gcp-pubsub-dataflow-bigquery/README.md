# GCP Pub/Sub Dataflow BigQuery

## Scenario

Build a GCP-native streaming analytics pipeline using `Pub/Sub`, `Dataflow`, and `BigQuery` with governed event contracts and observable freshness.

## Core Stack

- `Pub/Sub`
- `Dataflow`
- `BigQuery`
- `Cloud Monitoring`

## Skills To Apply

- `gcp-data-engineering`
- `streaming-and-messaging-systems`
- `data-observability-and-sla-management`
- `warehouse-performance-and-cost-optimization`

## Example Outcome

- governed event ingestion
- stateful processing and replay strategy
- serving tables in `BigQuery`
- measurable freshness and lag
