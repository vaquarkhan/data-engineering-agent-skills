# Data Publishing Contracts Checklist

Use this checklist before releasing shared datasets, extracts, or consumer-facing outputs.

## Contract

- [ ] Owner and audience are defined
- [ ] Schema and grain are explicit
- [ ] Delivery method is documented
- [ ] Freshness and retention expectations are defined

## Compatibility

- [ ] Breaking changes require versioning or notification
- [ ] Access boundaries are explicit
- [ ] Communication path exists for consumers

## Readiness

- [ ] Publish validation is complete
- [ ] Consumers are not relying on undocumented behavior
- [ ] Deprecation rules exist for future change
