# Data Platform Infrastructure Checklist

Use this checklist when reviewing infrastructure changes for data platforms.

## Environment Model

- [ ] Environment boundaries are explicit
- [ ] Naming and isolation rules are consistent
- [ ] Promotion path is defined

## Security

- [ ] Access roles are reviewed with the infrastructure change
- [ ] Secret management is explicit
- [ ] Destructive or high-risk changes are understood before apply

## Operations

- [ ] Manual dependencies are documented
- [ ] Day-two operations are considered
- [ ] Drift between environments is actively avoided
