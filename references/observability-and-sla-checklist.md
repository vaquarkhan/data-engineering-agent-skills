# Observability And SLA Checklist

Use this checklist when hardening production data products.

## Service Definition

- [ ] Owner and escalation path are defined
- [ ] Freshness SLA is defined
- [ ] Completeness or reliability expectations are defined

## Signals

- [ ] Run health signals exist
- [ ] Freshness is measured
- [ ] Volume or anomaly signals are tracked where needed
- [ ] Alerting includes enough context to act

## Operations

- [ ] Alerts route to the correct team
- [ ] Noisy or low-value alerts are reviewed
- [ ] Metadata exists to support diagnosis and trend analysis
