# Data Platform Operating Model Checklist

Use this checklist when defining service ownership and support expectations for a shared data platform.

## Service Catalog

- [ ] Supported platform capabilities are listed
- [ ] Golden paths are documented
- [ ] Self-service versus managed services are distinguished
- [ ] Service exclusions or unsupported patterns are explicit

## Ownership

- [ ] Platform-team ownership is defined
- [ ] Domain-team ownership is defined
- [ ] On-call or support expectations are clear
- [ ] Escalation paths are explicit

## Lifecycle Flows

- [ ] New source or dataset onboarding flow exists
- [ ] Access request flow exists
- [ ] Incident routing flow exists
- [ ] Decommissioning and retirement flow exists

## Guardrails

- [ ] Required contracts, validation, and evidence are explicit
- [ ] Golden paths are reflected in real docs or tooling
- [ ] Manual steps are minimized and documented when unavoidable
- [ ] Ownership is reviewable without tribal knowledge
