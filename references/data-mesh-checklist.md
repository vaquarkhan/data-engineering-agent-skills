# Data Mesh Checklist

Use this checklist when reviewing domain-oriented data product design.

## Ownership

- [ ] Domain ownership is explicit
- [ ] Data products have named owners
- [ ] Platform and domain responsibilities are separated

## Product Discipline

- [ ] Data products have contracts and consumers
- [ ] Service expectations such as freshness and support are defined
- [ ] Discoverability and lineage expectations are covered

## Governance

- [ ] Federated standards exist
- [ ] Domains are not making incompatible local choices without review
- [ ] "Data product" is not being used as a label without real operational commitments
