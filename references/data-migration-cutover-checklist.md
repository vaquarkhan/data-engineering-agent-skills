# Data Migration Cutover Checklist

Use this checklist when migrating data systems or cutting consumers over to a new platform.

## Planning

- [ ] Source and target systems are explicit
- [ ] Affected datasets, jobs, and consumers are identified
- [ ] Cutover pattern is chosen intentionally

## Validation

- [ ] Reconciliation gates are defined
- [ ] Performance or cost acceptance criteria are defined where relevant
- [ ] Rollback is executable

## Completion

- [ ] Consumer cutover is confirmed
- [ ] Old-path retirement is planned
- [ ] The migration does not leave two unclear sources of truth behind
