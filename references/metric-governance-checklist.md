# Metric Governance Checklist

Use this checklist when defining or changing shared business metrics.

## Definition

- [ ] Metric owner is named
- [ ] Business meaning is explicit
- [ ] Grain, filters, and exclusions are documented
- [ ] Numerator and denominator logic are clear where relevant

## Consistency

- [ ] Shared dimensions are standardized
- [ ] Downstream consumer impact is considered
- [ ] Duplicate conflicting KPI definitions are not left unresolved

## Change Control

- [ ] Breaking definition changes have communication or migration support
- [ ] Historical comparability implications are considered
