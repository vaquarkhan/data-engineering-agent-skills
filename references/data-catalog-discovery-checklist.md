# Data Catalog Discovery Checklist

Use this checklist when publishing or curating shared datasets in a catalog.

## Metadata

- [ ] Owner is named
- [ ] Business description is clear
- [ ] Grain and freshness expectations are documented
- [ ] Tags support real discovery, not only taxonomy completeness

## Trust

- [ ] Lineage or source context is attached
- [ ] Quality or certification status is visible
- [ ] Deprecated assets are marked clearly

## Operations

- [ ] Metadata is updated when contracts change
- [ ] Discovery quality helps users choose trusted assets over duplicates
