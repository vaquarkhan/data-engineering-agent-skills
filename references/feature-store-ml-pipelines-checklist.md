# Feature Store ML Pipelines Checklist

Use this checklist when building ML-oriented data products and feature pipelines.

## Correctness

- [ ] Feature meaning and entity keys are documented
- [ ] Point-in-time correctness is protected
- [ ] Offline and online parity expectations are explicit

## Operations

- [ ] Feature freshness is monitored
- [ ] Missing or stale feature behavior is defined
- [ ] Producers and consumers are known

## Lifecycle

- [ ] Features have ownership and deprecation paths
- [ ] Training-serving drift risk is reviewed
