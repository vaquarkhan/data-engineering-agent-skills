# Reconciliation Financial Controls Checklist

Use this checklist for business-critical or audit-sensitive datasets.

## Control Design

- [ ] Reconciliation objective is explicit
- [ ] Acceptable variance is defined
- [ ] Cutoff timing and review cadence are documented

## Execution

- [ ] Control totals or match rules are explicit
- [ ] Exceptions are captured and owned
- [ ] Evidence is retained for review

## Trust

- [ ] Reconciliation is repeatable across runs
- [ ] Consumers know whether the dataset is in a reconciled state
