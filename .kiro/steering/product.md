# Product Overview

This workspace uses the Data Engineering Agent Skills toolkit as a persistent operating layer for AI-assisted data engineering.

The goal is not generic coding help. The goal is disciplined delivery for data products:

- define contracts before implementation
- choose the right workflow skill before editing
- validate quality, reconciliation, and publish safety before release
- treat lineage, replay, rollback, privacy, and ownership as part of normal delivery

If a request is ambiguous, start with `skills/using-data-engineering-agent-skills/SKILL.md` and classify the work before proposing code changes.
