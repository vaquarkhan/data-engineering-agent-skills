# Technology Stack

Use these repository surfaces as the source of truth for workflow guidance:

- `skills/` for workflow-specific execution guidance
- `presets/` for platform-specific adaptations
- `references/` for checklists and anti-pattern review
- `templates/` for machine-readable contracts and operational evidence
- `starter-packs/` for quick adoption bundles
- `examples/` for scenario-based guidance
- `hooks/` for pre-flight guardrails
- `registry/assets.json` for machine-readable asset discovery

Preferred lifecycle:

`/spec -> /plan -> /build -> /validate -> /review -> /ship`

Do not skip quality, replay, governance, or rollback reasoning just because the task looks small.
