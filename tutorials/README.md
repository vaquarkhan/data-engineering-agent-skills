# Tutorials

This folder contains longer-form walkthroughs for people who want more than a quick setup guide.

Use these tutorials when you want a step-by-step adoption path instead of only a reference document.

## Included Tutorials

- `tutorials/using-data-engineering-agent-skills.md`  
  Full walkthrough for understanding the repository, choosing skills and presets, using lifecycle commands, and adopting starter packs, templates, hooks, and examples.
- `tutorials/installing-vscode-and-jetbrains-plugins.md`  
  Detailed install and usage tutorial for the `VS Code` family extension and the `JetBrains` plugin.
- `tutorials/cloud-data-engineering-architecture-patterns.md`  
  Step-by-step tutorial for choosing common cloud data platform shapes across lake, warehouse, lakehouse, streaming, and hybrid architectures.
- `tutorials/pipeline-orchestration-patterns.md`  
  Guided tutorial for selecting scheduler-driven, event-driven, and lakehouse-native orchestration patterns across major clouds.
- `tutorials/streaming-architecture-patterns.md`  
  Applied walkthrough for event backbone, CDC, replay-safe sinks, DLQ, lateness, and state-recovery design choices.
- `tutorials/data-resiliency-testing-patterns.md`  
  Practical tutorial for failure drills, restart behavior, replay safety, backlog catch-up, and publish-protection testing.
- `tutorials/etl-elt-modernization-and-cutover.md`  
  Detailed walkthrough for choosing `ETL`, `ELT`, or hybrid modernization patterns with parity, cutover, and retirement planning.
- `tutorials/regulated-data-and-compliance-workflows.md`  
  Guided tutorial for regulated-data classification, lineage, controls, audit evidence, retention, deletion, and publish readiness.
